# 跨层全连接计算资源复用实验报告

## 实验设置

同一MNIST测试集前1000张，同一参数，16位数据、6位整数，32位累加器、14位整数。两版均使用Vivado HLS 2019.2、XC7Z020和10ns目标周期，采用优化C仿真。原版来源为仓库b5edae1。

这是体系结构控制变量实验，未重做同学的8～16位精度扫描。1000张用于验证改造的一致性，不能把子集准确率代替10000张结果。

## 设计变更

原版三层FC拥有各自循环；复用版设置统一输入缓冲256、权重缓冲30720、bias缓冲120、输出缓冲120。阶段计数器stage依次选择FC1、FC2、FC3的参数、输入长度和输出长度，装载当前层参数后调用同一个dense_shared函数。函数禁止内联，源码只有一个调用点。

这项改造同时引入片上权重缓存与装载阶段，因此资源/时延差值是整套复用架构的结果，不能全部归因于单独的乘法器共享。

## 工程结论

资源变化（正数为增加，负数为减少）：DSP: -70.00%, LUT: -6.87%, FF: -3.34%, BRAM: +253.85%。选择配置时同时核查存储和计算资源预算。

按目标周期换算，原版延迟18.594ms，共享版综合范围16.573～30.997ms。动态循环上界导致范围变宽，尚不足以证明加速，需RTL协同仿真测量实际周期。

DSP变化为 -7，BRAM变化为 33。复用必须同时考虑缓存容量、控制与访存代价；是否适合部署不能只看DSP。

HLS延迟和时钟为综合估算，不是布局布线或上板测量。共享函数带有动态循环边界，若报告给出范围或未知值，不能将最大tripcount估算当作实测总延迟。
